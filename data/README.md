# Datos observacionales

Los datos observacionales utilizados en este trabajo no se redistribuyen en este repositorio.

Los análisis emplean:

- DESI DR1 BAO.
- Pantheon+SH0ES para supernovas de tipo Ia.
- Priors de distancia del CMB, incorporados directamente en los scripts correspondientes.

Los datos originales deben obtenerse de sus fuentes oficiales. Las referencias y enlaces utilizados se indican en la memoria del TFM y se incluirán también en el `README.md` principal del repositorio.

En el caso de Pantheon+SH0ES, el análisis utiliza una versión preprocesada de los datos. El procedimiento aplicado se describe en la memoria del TFM. El archivo resultante de dicho preprocesado no se redistribuye aquí.

Los scripts están preparados para trabajar con los datos almacenados localmente, indicando la ruta correspondiente mediante sus argumentos de ejecución.
